About

This visualization shows the current LangGraph workflow architecture.

Flow: START → validation → agent → tools → agent (synthesis) → END

Conditional edges (thick, orange) represent dynamic routing decisions by the agent.

Regular edges (thin, solid) represent unconditional transitions.

Return edges (dashed) show tools returning results to the agent for synthesis.
